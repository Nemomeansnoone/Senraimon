# Senraimon

### Pokemon battles, but its war thunder!


## _What is it?_

Senraimon is a war thunder themed pokemon style turned based combat minigame, made for me to learn how to use tkinter in python!


## _Why the name?_

Senrai = war thunder in japanese (plus the whole senrai maidens shebang) + mon = poke**mon**


## _How do i run it?_

As of now, it is still a work in progress so there are no runnable files, please be patient!
