# Senraimon
### Pokemon battles, but its war thunder!

## _What is it?_
Senraimon is a war thunder themed pokemon style turned based combat minigame, made for me to learn how to use tkinter in python!

## _Why the name?_
Senrai = war thunder in japanese (plus the whole senrai maidens shebang) + mon = poke**mon** LMAO

## _How do i run it?_
There is a build compiled for macOS available at releases (no windows or linux builds yet since i do not yet have access to devices with either OS), if you do not have macOS or don't want to use the pre-compiled build, you can run the program by doing the following

**IMPORTANT: the following dependancies are required for the program to function: python-tk, pillow**

**Also important: make sure all files are in the same directory as the file will not function properly otherwise**
### Windows:
open a command prompt window, cd to the directory where all the files are and run the following command:

```python senraimon.py```
### macOS:
open a terminal window, cd to the directory where all the files are and run the following command:

```python3 senraimon.py```
### Linux:
open a terminal window, cd to the directory where all the files are and run the following command:

```python3 senraimon.py```
